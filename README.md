## 📐 整理规范

每个收录的项目在对应分类目录下建独立文件夹：

```
<分类>/<项目名>/
└── README.md   # 中文说明：是什么 / 能干什么 / 怎么装 / 怎么用
```

中文 README 统一包含：

1. **一句话简介** —— 这个项目是干什么的
2. **核心亮点** —— 为什么值得用
3. **安装部署** —— 命令照抄可用，注释全部中文
4. **使用方法** —— 常用场景逐步演示
5. **原仓库链接** —— 尊重原作者，注明出处与协议
